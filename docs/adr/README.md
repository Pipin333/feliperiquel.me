# Architecture Decision Records (ADRs)

Este directorio documenta las decisiones arquitectónicas fundamentales tomadas en el desarrollo de [feliperiquel.me](https://feliperiquel.me), siguiendo el estándar de **Architect-Guardian**.

Cada ADR registrado cumple rigurosamente con tres criterios:
1. **Difícil de revertir**: El coste técnico de retroceder o cambiar de opinión es significativo.
2. **Sorprendente sin contexto**: Una persona o agente de IA que revise el código podría no entender la razón detrás de la decisión sin la arqueología previa.
3. **Fruto de un trade-off real**: Existían al menos dos alternativas viables analizadas y se optó por la más conveniente para el sistema.
